# Module 4 - Machine Learning Basics

## Iris Flower Classification

This module focuses on the basics of Machine Learning using Python and Scikit-learn.

### Objective

Build a beginner Machine Learning classification model using the Iris dataset.

### Work Completed

- Loaded and explored the Iris dataset
- Visualized the dataset
- Prepared features and target
- Split data into training and testing sets
- Built a K-Nearest Neighbors (KNN) model
- Trained the model
- Made predictions
- Evaluated model performance using:
  - Accuracy
  - Confusion Matrix
  - Classification Report
- Tested the model with a new flower sample

### Tools & Libraries

- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
