# Module 5 - Data Science Mini Project

## Customer Shopping Intelligence & Segmentation

### Codomax Data Scientist Internship

This project analyzes customer shopping behavior to identify purchasing patterns, customer segments, and potential business opportunities.

## Project Objective

The objective of this project is to transform customer shopping data into meaningful insights through data cleaning, feature engineering, exploratory data analysis, customer segmentation, and visualization.

## Key Areas of Analysis

- Customer demographics
- Product and category performance
- Customer spending behavior
- Seasonal purchasing patterns
- Subscription and discount behavior
- Payment method preferences
- Purchase frequency
- Customer spending segments
- Relationships between customer behavior variables

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The project uses the Customer Shopping Trends dataset.

## Project Workflow

Data Understanding → Data Quality → Data Cleaning → Feature Engineering → Exploratory Data Analysis → Customer Segmentation → Visualization → Insights → Business Recommendations

## Outcome

The project demonstrates how raw customer data can be transformed into business-oriented insights that can support customer analysis and decision-making.

Advanced predictive machine learning is intentionally reserved for the final project.
